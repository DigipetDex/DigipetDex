- **[중요] 유저 위키 편집이 실시간 배포 때 지워지던 문제 (10-02 ~ 10-07, 약 50건 유실):** 에디터 수정 보호(10-02 도입)가 시트 병합 뒤 기준값만 저장하고 project 는 저장하지 않아, 다음 에디터 실행 때 "저장된 옛 project ≠ 기준값" → 유저 편집을 관리자 수정으로 오인 → 실시간 배포가 옛 값으로 덮어씀. 병합 뒤 `saveState()` 가 성공했을 때만 기준값 저장, `saveState()` 는 성공 여부 반환, 기준값 키 `digipet_live_baseline_v4` 로 잘못된 기준값 폐기. 재현 테스트(에디터 3회 실행 + 배포)로 예전 코드 유실/새 코드 유지 확인

- **변경 기록·복구 장치:**
  - [GAS] 실시간 배포로 값이 바뀐 진화선을 `위키_변경역사` 에 편집자 "관리자 배포" 로 기록 (`recordSyncHistory`, 이전 값/새 값 JSON 포함)

  - 위키 역사의 "관리자 배포" 항목에 [↩ 배포 전 값으로] 버튼 (에디터 전용, prevData 로 되돌림 — 최신 항목이 아니어도 가능)
