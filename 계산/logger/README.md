# DIGIPET 전투 기록 봇

DIGIPET_Vital Link의 전투 결과를 자동으로 기록하고, 명중률·데미지·승률 통계를 보여주는 비공식 팬 봇입니다.
같은 조건으로 여러 판 싸웠을 때 실제 명중률과 데미지가 어떻게 나오는지 확인하는 데 씁니다.

- 게임 봇이 채널에 올린 메시지를 **읽기만** 합니다.
- 게임을 대신 플레이하거나 버튼을 누르지 않으며, 게임 진행에 아무 영향도 주지 않습니다.
- DIGIPET 개발진과 관계없는 개인 제작 봇입니다.

## 사용법

초대 후 따로 설정할 것은 없습니다. 평소처럼 `/배틀`, `/탐험`을 하면 끝난 전투가 자동으로 기록됩니다.

| 명령 | 설명 |
|---|---|
| `/통계` | 가장 최근 전투와 같은 조건(같은 디지몬·같은 스탯)의 누적 통계 |
| `/통계 범위:전체 개수:N` | 이 채널의 조건별 통계를 판수가 많은 순으로 N개(기본 10) |
| `/알림 상태:켜기 간격:N` | N전마다 현재 조건의 통계를 채널에 자동으로 올림 (기본 꺼짐, 간격 기본 10) |
| `/알림 상태:끄기` | 자동 알림 끄기 |
| `/알림 상태:횟수 초기화` | 알림용 배틀 횟수를 0부터 다시 셈 (기록·통계는 그대로) |

알림의 "배틀 N회"는 같은 조건(같은 디지몬·스탯)으로 연속 진행한 판수입니다. 다른 디지몬으로 바꾸거나 훈련으로 스탯이 바뀌면 자동으로 1부터 다시 셉니다.

모든 명령은 **명령을 입력한 채널의 기록만** 보여줍니다. 다른 채널이나 다른 서버의 기록은 보이지 않습니다.

### 통계 읽는 법

```
[탐험] 제스몬 410/190/215 vs 야생 — 2전
승리: 야생 1, 코퍼 1
코퍼의 제스몬: 명중 45.5% ±29.4 (11타, 예측 76.9%, 차이 -31.5 (±24.7)) / 평균 데미지 145.5 [144~146] (예측 139.0)
```

- `410/190/215`: 체력/전투력/속도
- `명중 45.5% ±29.4`: 실제 명중률과 오차 범위(95%). 공격 횟수가 적을수록 ±가 커집니다. 300타 정도 쌓이면 ±5 안팎이 됩니다.
- `예측`: 지금까지 모은 데이터로 추정한 공식이 계산한 값입니다. 공식은 아직 추정치입니다.
- `차이 -31.5 (±24.7)`: 실제 − 예측. 괄호 안은 공식이 맞더라도 운으로 생길 수 있는 범위입니다. 차이가 이 범위보다 크면 공식과 실제가 다르다는 뜻입니다.
- `평균 데미지 [최소~최대]`: 마지막 일격은 남은 체력만큼만 들어가서 평균에서 뺍니다.

### 집계 방식

- 같은 디지몬, 같은 스탯끼리 한 조건으로 묶습니다. 훈련으로 스탯이 1이라도 바뀌면 새 조건으로 따로 집계됩니다.
- 문장이 발현된 디지몬은 `410/190/215[용기]`처럼 문장을 붙여 따로 집계합니다.
- 탐험의 야생 적은 스탯이 매번 달라서, 내 디지몬 스탯 기준으로 묶고 상대는 `야생` 하나로 합칩니다.
- 전투가 끝까지 진행되어 결과가 나온 판만 집계됩니다. 전투 중 메시지를 지우면 기록되지 않습니다.

### 정확한 통계를 얻는 요령

- 알고 싶은 조건 하나를 정해 스탯을 바꾸지 않고 20판 이상 연속으로 합니다.
- 비교 실험(예: 속도만 다르게)은 한 번에 한 가지만 바꿉니다.

### 예측이 불안정한 경우와 필요한 기록

평소 전투도 모두 도움이 되지만, 아래 경우는 공식이 아직 불안정해서 기록이 특히 필요합니다.

| 불안정한 경우 | 무엇이 문제인가 | 필요한 기록 |
|---|---|---|
| 고전투력 (전투력 130 이상) | 실제 데미지가 공식보다 4~14 높게 나옴 | 전투력 130 이상 디지몬의 정규전 (상대 체력이 다양할수록 좋음) |
| 고체력·저전투력 장기전 (전투력 90 이하, 10턴 이상) | 그랜드로코몬(체력 투자 vs 속도 투자)이 개발자 수치 59.5%와 달리 73%로 나오고, 원인을 모름 | 전투력 70~90, 체력 400 이상끼리의 긴 전투 |
| 타수 경계 (상대를 쓰러뜨리는 데 3타가 필요할지 4타가 필요할지 애매한 경우) | 데미지가 1만 달라도 승률이 8%p 가까이 바뀜 (예: 쿠즈하몬) | 그 전투력·체력 조합의 실제 데미지 |
| 속도 차이가 큰 대결 (한쪽 속도가 상대의 절반 이하) | 명중률 기록이 적음 | 속도 차이가 큰 정규전 |
| 같은 종끼리 | 명중이 약 8.6%p 낮아지는 보정의 이유와 조건(이름 기준인지 종 기준인지)을 모름 | 같은 종 다른 이름 대결 (예: 아구몬 vs 아구몬(흑)) |
| 탐험 | 야생 상대 보정이 있는지 확인 중 | 탐험 전투 |
| 문장 (용기·우정·기적·희망·사랑) | 전투 화면 스탯에 문장 효과가 이미 들어가 있는지, 소수점 처리, 희망(체력 50% 이하)의 발동 시점을 모름 | 문장 디지몬의 `/상태` 확인 후 같은 스탯으로 정규전 |

## 수집하는 정보

게임 봇(DIGIPET_Vital Link)이 보낸 메시지만 읽습니다. **일반 사용자의 채팅은 읽거나 저장하지 않습니다.**

저장하는 것:
- 전투: 시각, 정규전/탐험 구분, 양쪽 디지몬 이름·속성·성장단계·문장·체력·전투력·속도, 상성, 승자
- 턴별 공격: 명중/빗나감, 데미지, 남은 체력
- `/상태` 화면의 디지몬 수치(문장, 바이탈, 우호도, 포만도, PP, 스탯, 배틀 수, 승률, 훈련 횟수)
- 전투 메시지에 표시된 플레이어 이름, `/배틀`·`/탐험` 명령을 쓴 사람의 서버 표시 이름
- 서버 이름, 채널 이름·ID

저장하지 않는 것: 일반 채팅, 사용자 ID, 이메일 등 계정 정보, 다른 봇의 메시지

기록은 봇 운영자의 기기에 채널별로 따로 저장되며, 전투 공식 분석 외의 용도로 쓰거나 외부에 공개하지 않습니다.
기록 삭제를 원하면 운영자에게 서버·채널을 알려 주세요. 봇을 서버에서 내보내면 그 뒤로는 기록하지 않습니다.
