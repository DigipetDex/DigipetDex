# DIGIPET 전투 기록 봇 안내

게임 봇(DIGIPET_Vital Link)이 채널에 올리는 전투·상태 메시지를 읽어 CSV로 기록하고, 통계를 보여주는 봇이다.
게임 봇의 메시지를 읽기만 하며, 게임을 대신 플레이하거나 버튼을 누르지 않는다.

## 수집하는 것

봇이 들어가 있는 모든 채널에서 게임 봇 메시지를 읽는다. 기록은 채널마다 `logs/ch-<채널ID>/` 폴더에 따로 쌓인다.

| 파일 | 내용 |
|---|---|
| `battles.csv` | 전투 1판당 1줄: 번호, 시각(KST), 모드(정규전 `regular` / 탐험 `explore`), 양쪽 이름·속성·성장단계·체력·전투력·속도, 상성, 승자, 양쪽 주인, `/배틀`·`/탐험`을 쓴 사람 |
| `events.csv` | 공격 1회당 1줄: 전투 번호, 턴, 주인, 디지몬, 명중/빗나감, 데미지, 공격 후 양쪽 HP |
| `status.csv` | `/상태` 화면: 바이탈, 우호도, 포만도, PP, 체력·전투력·속도, 배틀 수, 승률, 훈련 횟수 (값이 바뀔 때만 기록) |
| `components.jsonl` | 게임 봇 메시지의 버튼·메뉴 구성 (분석 참고용) |
| `channel.txt` | 서버 / 채널 이름 |

참고:
- 정규전(모의전)과 탐험 모두 기록된다. 탐험의 적은 `야생`으로 기록된다.
- 탐험의 야생 적은 스탯이 매번 랜덤이라, 통계에서는 내 디지몬 스탯 기준으로 묶고 상대를 `야생` 하나로 합친다.
- 전투가 끝까지 진행되어 결과 칸이 나와야 `battles.csv`에 1판으로 집계된다.
- 시각은 모두 한국 시간(KST)이다.

## 디스코드 명령어

명령을 입력한 채널의 기록만 대상으로 한다.

| 명령 | 설명 |
|---|---|
| `/통계` | 가장 최근 전투와 같은 조건(같은 디지몬·같은 스탯)의 누적 통계 |
| `/통계 범위:전체 개수:N` | 이 채널의 조건별 통계를 판수 많은 순으로 N개(기본 10) |
| `/알림 상태:켜기 간격:N` | N전마다 현재 조건 통계를 채널에 자동으로 올림 (기본 꺼짐, 간격 기본 10) |
| `/알림 상태:끄기` | 자동 알림 끄기 |

통계 한 줄 읽는 법:

```
코퍼의 제스몬: 명중 45.5% ±29.4 (11타, 예측 76.9%, 차이 -31.5 (±24.7)) / 평균 데미지 145.5 [144~146] (예측 139.0)
```

- `명중 45.5% ±29.4`: 실제 명중률과 오차 범위(95% 신뢰구간). 타수가 적을수록 ±가 커진다. 300타 정도면 ±5 안팎.
- `예측`: 그 판의 실제 스탯으로 현재 추정 모델이 계산한 명중률·데미지.
- `차이 -31.5 (±24.7)`: 실측 − 예측(%p). 괄호는 모델이 맞더라도 우연히 생길 수 있는 범위. 차이가 이 범위를 넘으면 모델과 어긋난다는 신호.
- `평균 데미지 [최소~최대]`: 마지막 일격은 남은 HP만큼 잘려서 평균에서 뺀다.

- 첫 화면: 채널 목록과 판수

  - 조건별 통계 카드 (최근 조건이 위). 열: 명중(오차), 예측, 차이(우연 범위), 타수, 평균 데미지, 예측 데미지, 범위

- 밖에서 보려면 폰과 보는 기기 모두 Tailscale에 연결한 뒤 `http://<폰 Tailscale IP>:8787/` (미확인).

## 데이터를 잘 모으는 요령

- 비교하고 싶은 조건 하나를 정해 같은 조건으로 20판 이상 연속으로 한다. 스탯이 1이라도 바뀌면 다른 조건으로 집계된다.
- 탐험은 같은 디지몬·같은 스탯으로 여러 판 돌리면 적이 달라도 한 카드에 합쳐진다.
- 전투 도중 메시지를 지우거나 채널을 옮기지 않는다.
- `/상태`를 가끔 열어 두면 스탯·훈련 변화가 `status.csv`에 남는다.

## 운영 (공기계)

- 설치 위치: `/data/data/com.termux/files/home/digipet-logger/`
- 부팅 시 자동 시작: `/data/adb/service.d/digipet-logger.sh` → `/data/adb/digipet-start.sh`
- 꺼지면 10초 뒤 자동 재시작. 실행 기록: `logs/logger.log`
- 재시작: 루트 셸에서 `for p in $(pidof node); do kill $p; done` (슈퍼바이저가 다시 띄움). `pkill -f`는 슈퍼바이저까지 죽이므로 쓰지 않는다.
- 슈퍼바이저까지 꺼졌으면: `sh /data/adb/digipet-start.sh`
- PC와 폰에서 동시에 실행하지 않는다 (같은 전투가 두 곳에 나뉘어 기록됨).

## 예측 모델

`model.js`에 현재 추정 공식이 있다 (`계산/sim/sim.js`와 같은 값, 자세한 근거는 `계산/전투 공식 정리.md`).

- 데미지 = round((0.8748 × 전투력 − 3.17) × (1 + 0.049 × 상성) × 100 / (100 + 0.05 × (방어자 체력 − 100))) ± 4
- 명중% = 32.75 + 0.87 × 100 × 내 속도 / (내 속도 + 상대 속도) + 6.2 × 상성 − 8.6 × 같은 종
- 상성: 유리 +1, 불리 −1, 중립 0 (백신 > 바이러스 > 데이터 > 백신, 프리는 중립, 불명은 백·바·데에 유리)

전투력 150 이상, 체력 250 이상, 탐험 구간은 아직 검증 중이라 예측이 어긋날 수 있다.
